## Features Implemented

### 1. Agent Node Full-Screen Display in Watch Screen
- Agent images now fill the entire watch screen (202x202 pixels)
- Used CSS `:has()` selector to expand `.watch-display` container when it contains an Agent
- Image maintains aspect ratio with `object-fit: cover`

**Files Modified:**
- `comfyui.js` (lines 2254-2275) - Agent-specific watch display logic
- `styles.css` (lines 4210-4238) - Full-screen agent display styles

### 2. Hero Type Badge Overlay
- Hero/Mentor/Villain badge now overlays the Agent image at bottom center
- Color-coded badges:
  - Hero: Blue gradient (#3b82f6 to #1d4ed8)
  - Mentor: Green gradient (#22c55e to #15803d)
  - Villain: Red gradient (#ef4444 to #b91c1c)

**CSS Added:**
```css
.watch-agent-display .watch-hero-badge {
    position: absolute;
    bottom: 10px;
    left: 50%;
    transform: translateX(-50%);
}
```

### 3. Watch Frame Glow Effect During AI Generation
- Animated purple glow effect when generating AI content
- 1.5s pulsing animation cycle
- Glow class: `.generating-glow`

**CSS Added:**
```css
.watch-frame.generating-glow {
    border-color: var(--accent-primary);
    animation: watch-glow-pulse 1.5s ease-in-out infinite;
}
```

### 4. Fixed AI Generation for Agent Nodes
- Fixed bug where Agent nodes with "Generated by the agent" dataSource weren't generating
- Updated 4 locations in `comfyui.js` to check for both:
  - `'Generated by AI'`
  - `'Generated by the agent'`

**Lines Fixed:**
- Line 2028-2029: First node generation check
- Line 2107: AI badge display
- Line 2329-2330: updateWatchDisplay check
- Line 2381-2382: nextSimulationStep check

### 5. Node Title Always Visible
- Title now always shows in watch screen (including for Agent nodes)
- Previously Agent nodes hid the title

### 6. Removed "Generating..." Text Overlay
- Cleaner UX: just the glow effect during generation
- No overlapping text during generation phase

### 7. Chat Model Update
- Changed from `claude-3-haiku-20240307` to `claude-opus-4-5-20251101`
- Increased temperature from 0.7 to 1.0
