# IDEA Engine - Node Documentation

This document provides a comprehensive overview of all available nodes in the IDEA Engine workflow editor.

## Data Types

All connections between nodes are type-safe. Here are the available data types:

| Type | Color | Hex Code |
|------|-------|----------|
| IMAGE | Purple | `#8b5cf6` |
| LATENT | Pink | `#ec4899` |
| MODEL | Orange | `#f59e0b` |
| CONDITIONING | Green | `#10b981` |
| CLIP | Blue | `#3b82f6` |
| VAE | Red | `#ef4444` |
| CONTROL_NET | Cyan | `#06b6d4` |

| STRING | Lime | `#84cc16` |
| BOOLEAN | Light Purple | `#a78bfa` |
| ANY | Gray | `#9ca3af` |
